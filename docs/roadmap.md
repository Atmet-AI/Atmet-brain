# Roadmap

The first release proves one shared core through local source capture, authorized learning, reviewed operating context, agent retrieval and recovery. Future work follows evidence and supported deployment needs; no dates are promised.

## Core hardening

- Evaluate semantic/vector retrieval against relevance, no-answer and access fixtures.
- Add durable provider-specific backoff, stronger job observability and larger-source chunking.
- Expand schema migration tooling and measure SQLite limits before selecting a server database adapter.
- Improve explicit retirement, review queues, configuration impact previews and historical inspection.
- Evaluate additional skill compatibility contracts and automatic evidence-linked skill drafts.
- Expand the tested repeated-task template library and evaluate representative edge cases and cost/latency. Keep ambiguous or judgment-based work on the agent path.
- Evaluate custom-code generation, isolated execution, shadow comparisons and deployment/rollback gates before supporting arbitrary Python or other languages. The current pure recipe runtime is not a general sandbox.

## Source coverage

- Gmail OAuth setup, token refresh, history cursors, attachments and live account validation.
- Additional business-tool adapters with explicit resource/audience mapping.
- Recording transcription and timestamped workflow evidence.
- Richer event correlation, process variants and quality evaluation before broad discovery claims.

## Clients and operations

- Remote MCP HTTP with interoperable authorization and actual client compatibility checks.
- Human login, trusted identity-provider mapping and delegated user access.
- A platform interface for sources, review, teams, skills, history, graphs and managed backups.
- Atmet Playground as a separate desktop coding runtime using the same core interfaces.
- Managed retention, recovery objectives, secret rotation and supported company-server packages.

Useful prior work can be evaluated as isolated components. A research repository is not automatically selected as a runtime dependency. See [references](references.md).
